# StoneAge

Landing page for StoneAge, a truly organic body wash. Designed in Figma and hand-coded as a single static page.

- Static HTML/CSS/JS, no build step. Deploy as-is on Vercel.
- Type: Geist Serif (headings, self-hosted, SIL OFL, see `fonts/OFL.txt`), Inter Display (body, Google Fonts), Tiro Bangla (wordmark, Google Fonts).
- Responsive from 1440 desktop down to mobile; respects `prefers-reduced-motion`.

## Annotating

Add `?annotate` to the URL on desktop to load the [Agentation](https://agentation.dev) toolbar (`vendor/agentation-bundle.js`, React 18 + agentation 3.1.2 bundled as one classic script). Click any element, leave a note, then Copy to get markdown feedback.
